Bâtiments et toits ​

Les bâtiments se décrivent dans propriete.ts. C'est du TypeScript : un éditeur comme VS Code complète et vérifie chaque champ, avec sa documentation au survol. Après chaque enregistrement, la page se met à jour.

Les bases ​

ts
import type { PropertyConfig } from '../../src/model/property';

export const propriete: PropertyConfig = {
  name: 'Ma maison',          // affiché dans la barre du haut
  courtyard: [9, 7],          // un point de la cour
  buildings: [
    {
      id: 'maison',
      name: 'Maison',
      kind: 'maison',
      sections: [{ id: 'maison' }],
      rooms: [
        { area: 'sejour', name: 'Séjour', level: 0 },
        { area: 'chambre', name: 'Chambre', level: 1 },
      ],
      facade: { sides: ['cour', 'dos'], gables: true, spacing: 2.6, shutters: '#5b7a8c', flowers: true },
      doors: [{ kind: 'entree', side: 'cour', at: -0.25, porch: true, lantern: true }],
    },
  ],
  parking: [], cars: [], pens: [], surfaces: [], gates: [], trees: [],
  fenceHeight: 1.4,
};
Champ
idIdentifiant libre, sans espace
nameNom affiché (résumé, panneau, étiquettes)
kindmaison, appartement, garage, abri, cabane ou poulailler : couleurs, icône et détails
sectionsLes volumes du bâtiment, chacun avec son toit (voir ci-dessous)
roomsLes pièces, reliées aux Zones de Home Assistant (Pièces et Zones)
viewD'où la caméra regarde le bâtiment sélectionné : cour (par défaut) ou dos

Sections ​

Une section est un volume sous un toit. Son id désigne une emprise de site.json. La plupart des bâtiments n'en ont qu'une ; une maison en L en a deux.

ts
sections: [
  { id: 'maison' },
  { id: 'aile', into: 'maison' },  // l'aile, dont le toit file dans celui de la maison
],

Les portes, fenêtres et baies d'un bâtiment à plusieurs sections précisent la leur avec section (son rang dans la liste, à partir de 0).

Toits ​

ChampEffet
roof: 'gable'Toit à deux pans (par défaut)
roof: 'shed', highSide: 1 | -1Toit à un pan (appentis) ; highSide dit quel côté est haut, sur l'axe z local
against: 'garage'Appentis adossé : son côté haut se cale sous la sablière du voisin, son toit en prolonge le pan
into: 'maison'Toit prolongé jusque dans le toit (plus haut) du voisin : la noue est calculée
merge: ['B0123']Deux emprises de site.json fusionnées sous un seul toit
open: trueAuvent : poteaux et sablière en bois, sans murs
rect: {…}Emprise donnée à la main, absente de site.json (un auvent que le cadastre ignore)
skew: [0, 12]Pignons en biais, en degrés (voir ci-dessous)

Pignons en biais ​

Un bâtiment accolé à un autre qui n'est pas d'équerre a souvent un bout en biais : il suit le mur du voisin. Chaque section est un rectangle dont chaque bout peut être oblique (un trapèze aux longs pans parallèles) ; le toit et les murs suivent.

  • Depuis le cadastre, c'est automatique : HAven lit l'emprise réelle, repère les bouts en biais (à partir de 2° environ) et les reproduit. Rien à écrire.
  • À la main (emprise rect, ou pour corriger) : skew: [début, fin] en degrés. Positif, le coin côté cour avance ; négatif, il recule. skew: [0, 0] remet les bouts d'équerre. L'éditeur de la page les règle aussi.

Quand un pignon est collé contre un voisin plus haut que lui sur toute sa largeur, son toit ne déborde plus et il n'a pas de mur propre : c'est celui du voisin qui ferme le bâtiment. Une porte percée dans ce voisin (side: 'pignon') donne alors directement dedans, comme une porte de maison qui ouvre sur un abri accolé.

Hauteurs ​

eave (sablière, le bas du toit) et ridge (faîtage, le haut) corrigent les hauteurs de site.json, souvent approximatives quand elles viennent du cadastre :

ts
sections: [{ id: 'garage', eave: 3.0, ridge: 6.0 }],

L'éditeur de la page fait la même chose au doigt.

Exemples tirés de la maison d'exemple ​

ts
// Garage accolé au dos de la maison : son toit file dans celui de la maison
{ id: 'garage', name: 'Garage', kind: 'garage',
  sections: [{ id: 'garage', into: 'maison' }], … },

// Appentis ouvert adossé au garage, avec un tas de bûches
{ id: 'abri', name: 'Abri de jardin', kind: 'abri',
  sections: [{ id: 'abri', roof: 'shed', highSide: 1, eave: 2.2, against: 'garage', open: true }],
  woodpile: { section: 0, from: -2.4, to: 2.4, height: 1.4 },
  view: 'dos', … },

Détails d'architecture ​

Champ

Leurs champs sont détaillés dans Façades, portes, fenêtres et la référence.
