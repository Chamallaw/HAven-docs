Façades, portes, fenêtres ​

Positions le long d'un mur ​

Portes, fenêtres, baies et escaliers se placent avec at (ou from / to) : des mètres depuis le milieu du mur, le long du faîtage. at: 0 est au milieu, at: -3 à 3 m vers le pignon « début ».

Le plus simple est de les relever : Relever une position, touchez le mur, lisez côté cour · at: 2.35.

Les fenêtres automatiques ​

facade perce les murs tout seul, à intervalle régulier, sur chaque niveau que la hauteur permet :

ts
facade: { sides: ['cour', 'dos'], gables: true, spacing: 2.6, shutters: '#5b7a8c', flowers: true },
Champ
sidesLongs pans percés : ['cour'], ['dos'] ou les deux
gablesFenêtres aussi sur les pignons dégagés
spacingÉcart entre fenêtres (m)
levelsNiveaux percés : [0], [1] ou [0, 1] (par défaut : ceux que la hauteur permet)
smallPetites fenêtres (dépendances, garage)
shuttersCouleur des volets battants ; sans volets si absent
flowersJardinières fleuries d'avril à octobre

Les fenêtres automatiques évitent les portes et les murs accolés à un autre bâtiment, sauf si ce voisin est plus bas qu'elles (une fenêtre de grenier au-dessus d'un appentis). Une fenêtre au-dessus de la sablière éclaire le grenier : elle ne s'allume avec aucune pièce.

Placer les fenêtres à la main ​

facade.windows place les fenêtres une à une. Sur un côté qui en a, elles remplacent le placement automatique.

ts
facade: {
  sides: ['cour', 'dos'], spacing: 2.6, shutters: '#5b7a8c',
  windows: [
    { side: 'cour', at: -4.2, level: 0 },
    { side: 'cour', at: 1.2, level: 0, width: 1.8, entity: 'cover.volet_salon' },
    { side: 'cour', at: 1.2, level: 1, closed: true },
    { side: 'pignon', end: -1, at: 0, level: 1, bare: true },
  ],
},
Champ
sidecour, dos ou pignon
endPour un pignon : extrémité 1 (+x) ou -1 (−x)
atPosition le long du pan (sur un pignon : en travers)
level0 rez-de-chaussée, 1 étage
sectionRang de la section, si le bâtiment en a plusieurs
width, heightTaille (m)
bottomHauteur de l'appui au-dessus du sol (m) : une fenêtre de grenier, par exemple
closedVolets fermés (ou porte de fenil en planches)
bareSans volets
entityCapteur d'ouverture (binary_sensor) ou volet roulant (cover) de cette fenêtre

Sans entity, les capteurs et volets roulants d'une pièce sont attribués dans l'ordre à ses fenêtres ; un volet roulant seul commande toutes les fenêtres de la pièce. Une fenêtre à volet roulant perd ses volets battants. Voir Ce qui est affiché et piloté.

Fenêtre derrière un bâtiment accolé

Les fenêtres automatiques évitent les murs accolés ; une fenêtre placée à la main, non.

Les portes ​

ts
doors: [
  { kind: 'entree', side: 'cour', at: -0.25, width: 1.0, height: 2.15, bottom: 0.3, porch: true, lantern: true, color: '#4f6b7a' },
  { kind: 'grange', side: 'cour', at: 1.0, width: 3.0, height: 2.4, entity: 'cover.porte_garage', lantern: true },
],
kind
entreePorte d'entrée ; avec porch, un auvent de tuiles et des marches
servicePorte de service, simple
cavePorte de cave, cintrée
grangePorte de grange à deux battants (garage)
passagePassage ouvert
trappeTrappe du poulailler : les poules sortent quand elle est ouverte
Champ
side, at, sectionOù la poser : cour, dos, ou pignon avec end (1 ou -1) et at en travers
width, heightTaille (m)
bottomSeuil au-dessus du sol (m)
entityLe cover de Home Assistant qui l'ouvre : la porte s'anime avec lui
openOuverture fixe de 0 à 1, sans entité (une porte restée entrouverte)
porchAuvent et marches
lanternLanterne murale à côté, allumée la nuit
colorCouleur du bois ou de la peinture

Baies, escaliers, colombages ​

ts
bays: [{ section: 0, from: -3, to: 3 }],                 // baie ouverte côté cour (abri à voitures)
stair: { side: 'cour', from: 4, to: 1, height: 2.6 },    // escalier extérieur du sol en 4 au palier en 1
timber: [2.7, 5.0],                                       // colombages entre 2,7 m et 5 m
chimney: true,
coop: { at: 0.5, width: 1.2, depth: 0.9, height: 1.0 }, // poulailler sous un auvent
woodpile: { section: 0, from: -2.4, to: 2.4, height: 1.4 },

Les champs complets sont dans la référence.
