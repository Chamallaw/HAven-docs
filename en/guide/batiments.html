Buildings and roofs ​

Buildings are described in propriete.ts. It is TypeScript: an editor such as VS Code completes and checks every field, with its documentation on hover. After each save, the page updates.

The basics ​

ts
import type { PropertyConfig } from '../../src/model/property';

export const propriete: PropertyConfig = {
  name: 'My house',           // shown in the top bar
  courtyard: [9, 7],          // a point in the courtyard
  buildings: [
    {
      id: 'maison',
      name: 'House',
      kind: 'maison',
      sections: [{ id: 'maison' }],
      rooms: [
        { area: 'living_room', name: 'Living room', level: 0 },
        { area: 'bedroom', name: 'Bedroom', level: 1 },
      ],
      facade: { sides: ['cour', 'dos'], gables: true, spacing: 2.6, shutters: '#5b7a8c', flowers: true },
      doors: [{ kind: 'entree', side: 'cour', at: -0.25, porch: true, lantern: true }],
    },
  ],
  parking: [], cars: [], pens: [], surfaces: [], gates: [], trees: [],
  fenceHeight: 1.4,
};
Field
idFree id, no spaces
nameDisplayed name (summary, panel, labels)
kindmaison (house), appartement (flat), garage, abri (shed), cabane (hut) or poulailler (chicken coop): colours, icon and details
sectionsThe building's volumes, each with its roof (see below)
roomsThe rooms, linked to Home Assistant Areas (Rooms and Areas)
viewWhere the camera looks at the selected building from: cour (default) or dos

Sections ​

A section is a volume under one roof. Its id refers to a footprint in site.json. Most buildings have just one; an L-shaped house has two.

ts
sections: [
  { id: 'maison' },
  { id: 'wing', into: 'maison' },  // the wing, whose roof runs into the house roof
],

Doors, windows and bays of a building with several sections give theirs with section (its index in the list, from 0).

Roofs ​

FieldEffect
roof: 'gable'Two-slope roof (default)
roof: 'shed', highSide: 1 | -1Single-slope roof (lean-to); highSide says which side is high, on the local z axis
against: 'garage'Lean-to against a neighbour: its high side tucks under the neighbour's eave, its roof continues the slope
into: 'maison'Roof extended into the (higher) roof of the neighbour: the valley is computed
merge: ['B0123']Two site.json footprints merged under a single roof
open: trueOpen shelter: wooden posts and beam, no walls
rect: {…}Footprint given by hand, absent from site.json (a shelter the land registry ignores)
skew: [0, 12]Skewed gables, in degrees (see below)

Skewed gables ​

A building attached to another that isn't square to it often has a skewed end: it follows the neighbour's wall. Each section is a rectangle whose ends can each be oblique (a trapezoid with parallel long sides); the roof and walls follow.

  • From the land registry, it's automatic: HAven reads the real footprint, spots skewed ends (from about 2°) and reproduces them. Nothing to write.
  • By hand (a rect footprint, or to correct): skew: [start, end] in degrees. Positive, the courtyard-side corner moves out; negative, it moves in. skew: [0, 0] squares the ends again. The in-page editor adjusts them too.

When a gable is against a neighbour that is taller across its whole width, its roof no longer overhangs and it has no wall of its own: the neighbour's wall closes the building. A door in that neighbour (side: 'pignon') then opens straight into it, like a house door opening onto an attached carport.

Heights ​

eave (bottom of the roof) and ridge (top) correct the heights from site.json, often approximate when they come from the land registry:

ts
sections: [{ id: 'garage', eave: 3.0, ridge: 6.0 }],

The in-page editor does the same with your finger.

Examples from the example house ​

ts
// Garage attached to the back of the house: its roof runs into the house roof
{ id: 'garage', name: 'Garage', kind: 'garage',
  sections: [{ id: 'garage', into: 'maison' }], … },

// Open lean-to against the garage, with a woodpile
{ id: 'abri', name: 'Garden shed', kind: 'abri',
  sections: [{ id: 'abri', roof: 'shed', highSide: 1, eave: 2.2, against: 'garage', open: true }],
  woodpile: { section: 0, from: -2.4, to: 2.4, height: 1.4 },
  view: 'dos', … },

Architectural details ​

Field
timber: [2.7, 5.0]Exposed half-timbering between these two heights (m): a timber-framed upper floor on a rendered ground floor
chimney: trueA chimney, smoking when it's chilly
woodpileWoodpile under a shelter, against the wall on the high side
coopWooden chicken coop under a shelter; its hatch is the building's trappe door
stairOutside staircase along a long side
baysLarge open bays (carport)

Their fields are detailed in Facades, doors, windows and the reference.

SymptomFix
