plans.ts ​

Référence des plans intérieurs ; le schéma fait foi dans src/model/plans.ts. Guide : Plans intérieurs.

ts
export const plans: Record<string, InteriorPlan> = { /* identifiant de bâtiment → plan */ };

Repère propre à chaque bâtiment (sa première section) : X le long du faîtage depuis le nu extérieur du pignon « début », Z en travers depuis le nu extérieur du mur côté dos. Rectangles PlanRect : [X0, Z0, X1, Z1] en mètres.
